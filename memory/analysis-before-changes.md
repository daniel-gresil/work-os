When Dan hands over a new request (an email, a complaint, a task), start with a read-only analysis: what is going on, what the options are, one recommendation. Make no change to any sheet, repo or system until he has read it and says go.

**Why:** On 2026-10-05, mid-analysis of the WIP Lavanderia memory error, Dan stopped the session with "Don't make any changes. Just do an initial analysis."

**How to apply:** Inventory, measure, dry-run. Present findings with a recommended plan, then wait. Once he approves, go one step at a time; see [[ask-questions-one-at-a-time]] and [[approve-means-proceed]].
