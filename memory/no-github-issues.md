Tasks and issues go to the ADO board through the `ado-add-task` skill, never to GitHub Issues.

**Why:** Dan does not use the GitHub Issues module. The Matt Pocock engineering skills default to it, so they must be steered away. The GitHub Issues convention was removed from the global CLAUDE.md on 2026-10-05.

**How to apply:** When a skill or doc suggests `gh issue` or a `.scratch/` issue file, use ADO instead. See [[approve-means-proceed]] for how much to bring back for decisions.
